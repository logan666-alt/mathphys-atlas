# 从化学势导数看熵、热容与相变

日期：2026-10-29。原专题新增第四步，入口 `/#/resource/three-phase?step=4`。

## 物理与教学

- 固定压强、固定其他外场，讨论单组分摩尔 Gibbs 自由能。由 `dμ = −Sₘ dT + Vₘ dp` 推导 `Sₘ = −μ_T`、`Cₚ,ₘ = −T μ_TT`；说明单位和适用路径。
- 一级相变直接沿用前三步的三相模型。汽化、熔化、升华均使用同一化学势、熵和焓；局部温区根据相邻相界收窄，确保两端的分支确为三相下包络。
- 统一使用 `τ = T/T*`、`g = μ/(RT*)`、`s = Sₘ/R`、`c = Cₚ,ₘ/R`。一级相变的 T* 从原模型共存条件求出；连续相变中 T* = Tc。
- 一级相变的相内 `c = 3`，相变的潜热项在热容图中用 δ 箭头表示，面积为 `Lₘ/(RT*) = Δs`。相变点的普通导数显示无唯一值，同时显示左右极限。共存比例在固定温度下改变熵和焓。
- 连续相变热容跳跃模型来自对序参量极小化后的 Landau 自由能：低温侧额外项 `−6(τ−1)²`。g、g′ 连续，热容左右极限为 15、3，潜热为零。
- 连续相变发散模型使用局部项 `1.5 x² ln|x| − 2.25 x²`，x = τ−1。g、g′ 连续，c 对数发散；解析积分有限。图中超出纵轴部分明确标示，积分读数包含完整贡献。
- 熵变积分模式显示 `c/τ` 的阴影面积，一级相变贡献单列；热量读数由同一模型的焓差计算。减去共同直线选项只改变绘图高度和斜率基准，曲率不变，原导数读数保留。
- 页面给出推导、300 K/10 J mol⁻¹ K⁻¹ 的潜热例题、分类比较和主要参考资料。说明连续不等于有限温区内熵不变，也说明一般相变须结合控制路径及其他自由能导数。

## 交互

- 三种相变情景共用三图游标。支持温度滑块、相变前/相变点/相变后按钮，以及在任一曲线图内横向拖动。
- 一级情景可选汽化/熔化/升华、固定压强；共存点可调高温相比例。提供返回对应三维共存点的入口。
- 模型、相界、压强、温度位置、相比例和绘图选项写入原专题链接；刷新可恢复。
- 沿用前三步的三维场景和自由视角。
