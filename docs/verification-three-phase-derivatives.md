# 三相图与化学势：从导数看相变

日期：2026-10-29（物理量与单位修订）

入口：`/#/resource/three-phase?step=4`

## 教学表达与模型

- 全专题直接使用 T、p、μ、Sₘ、Cₚ,ₘ。温度输入 K、压强输入 kPa；化学势和摩尔焓显示 J/mol，摩尔熵和摩尔热容显示 J/(mol·K)，摩尔体积显示 L/mol。总量约束输入 L 或 J。
- 移除归一化符号及减去共同直线的选项。斜率和二阶导数直接取自所画的化学势曲线，以完整文字解释熵跃变、潜热和热容。
- 三相教学模型的三相点设为 300 K、100 kPa，共同化学势为 0 J/mol；参数用于教学，不对应具体物质。原三维模型的几何形状和共存关系保持不变。
- 一级相变沿用前三步模型。汽化、熔化、升华的两相化学势相等，斜率不同。熵跃变以两相摩尔熵之差表示，每摩尔潜热等于相变温度乘以该差值。
- 连续相变用相变温度 300 K 的两个局部模型。热容跳跃例的左右极限为 124.72 和 24.94 J/(mol·K)；对数发散例的熵连续、热容发散且积分有限。两例潜热均为零。
- 三张图共用实际温度游标。熵变面积模式绘制 Cₚ,ₘ/T，单位 J/(mol·K²)；面积单位为 J/(mol·K)。一级相变的潜热贡献另用箭头标出，切换面积模式时箭头改为熵跃变。
- 共存点的化学势一阶、二阶导数不作为单一数值显示。相比例决定转化进度；相内热容与潜热分别说明。

## 核验

- 全站 38 项测试通过。除原有相界、守恒、潜热与积分检查外，新增以 K 为自变量的独立有限差分检查，核对化学势斜率、二阶导数、熵和焓的温度导数。
