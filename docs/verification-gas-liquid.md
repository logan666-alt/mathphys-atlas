# 气液相变专题核验

日期：2026-10-24。入口：`#/resource/gas-liquid`。

## 数值模型

- 约化范氏方程 `pr = 8Tr/(3vr−1) − 3/vr²`；由同一方程积分得到摩尔自由能，再用 `μ = Fm + pVm` 计算化学势。
- 在 Tr = 0.85、0.90、0.95、0.98、0.99、0.995、0.999 核对共存两端与中间根的压强，液气化学势相等，以及两块解析面积相等。
- Tr = 0.90：ps/pc = 0.646998351872251，Vmℓ/Vmc = 0.603401903178003，Vmg/Vmc = 2.348842376202230。两块面积均为 0.061753（单位 pcVmc，界面保留六位小数）。
- 非共存压强下，核对 `μg−μℓ = Sbelow−Sabove`，其符号与试画压强相对共存压强的高低一致。
- 核对杠杆规则、各均匀相分支的机械稳定性、有限差分 `dμ/dp = Vm`，以及临界点的一阶和二阶体积导数。
- 静态目录检查通过；全部 19 项自动检查通过，其中新增 7 项覆盖相平衡模型、临界点和专题公式。

## 浏览器操作

在本机内置浏览器实测：

- 默认从纯气体起点开始；压缩至两相平台后，液相物质的量分数更新。播放、暂停、达到终点后重播均可用。
- 选择 AJ 和 NB 后，分别显示过热液体和过饱和蒸气；JDN 说明机械不稳定。
- 移动试画水平线到最低与最高位置，分别得到气体更有利与液体更有利的提示；较低压强下横轴扩展以容纳气相根。
- 点击定位等面积压强，面积相同、化学势差归零；Tr = 0.98 时两块面积均为 0.002414。
- 选择临界点和高于临界温度，有限长度平台消失，显示水平拐点或单调等温线。
- 带参数链接刷新后保留温度、步骤和压强位置；不带参数入口恢复 Tr = 0.90、压缩进度为零。
- 320 和 390 CSS 像素宽度下，文档无横向溢出，图中文字和读数可见；主图无非有限坐标。已修正 SVG 容器隐藏方式，避免切换步骤后留下空白容器。
- “热力学与统计物理 + 等面积”组合筛选得到本专题；原焦耳—汤姆孙页面仍可打开。
