## 发现的问题与处理

- VisualPDE 一维波动：默认 D=1 短时运行正常。另测 D=4 时，黑色叠加线与彩色数值解分离，随后出现数值不稳定提示。查看实际叠加表达式发现它使用 x±D·t，而给定方程的波速是 √D。导读保留默认值，并说明重新打开默认链接才会恢复参数；没有把它当作精度验证。
- VisualPDE 驻波说明：对 u_tt=D∇²u，频率应含 √D。本站按代入方程核对后的表达式书写。
- VisualPDE 有源热方程：原文稳态符号与所列源项不符，且温度平方积分不能直接当总热量式。本站分别写明代入检验及温度积分平衡，不照抄错误。
- VisualPDE 一维热方程：说明中一处初值遗漏 x，当前界面确实为 cos(m*pi*x/320)。本站给出含 x 的表达式。m=2 / 8 的定时衰减测量未完成，保持“操作部分核验”。
- VisualPDE 定向对流：当前预设导数项位于右边且为加号，v=−V(cosθ,sinθ)。本次 V=2、θ=0 与 1.57 的移动方向与该符号一致；未照搬说明页的另一符号约定。
- Falstad 静电：切换示例后曾暂时黑屏。全屏入口在绘制完成后成功显示两正电荷、偶极子和接地平面；使用该具体入口，并写明等待绘制及备用说明入口。未安装 Java。
- 高教社梁昆淼书目：最后 HTTP 复查中，桌面书目入口发生 TLS/超时失败。出版社同一本书的移动版入口成功读取完整目录，已替换正式链接。失败记录保留在 link-check.json。
