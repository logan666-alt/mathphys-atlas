# 三相第二版修订：共用三维空间与自由视角

日期：2026-10-27。按用户反馈，取消分开展示；在同一坐标系适度放大曲面间高低差，增加三维自由观察操作。

## 当前实现

- 三张曲面始终共用一个坐标系。绘制实际g，统一拉伸纵轴1–4倍，默认2.5倍；无逐相高度偏移，无液相参考曲面相减。数值、相序与物理交点不变。整体自动取景保留曲面，缩放独立控制。
- 360°水平旋转、−85°至85°俯仰、0.6–2倍缩放，默认转向−35°、俯仰15°。鼠标/单指拖动控制两个方向，滚轮及双指距离控制缩放；支持方向键、＋/−、Home和可展开滑块。
- WebGL深度缓冲渲染曲面与网格，避免旋转后多边形绘制先后造成的错误遮挡；不支持WebGL时回退到SVG。坐标轴、选点与共存交线为前景辅助标记。
- 指针移动仅重绘三维场景。相机参数保存进链接；复位恢复默认转向、俯仰、缩放，保留选中的物理状态和高度差倍数。旧分屏链接兼容为共用场景。
- 保留第二版三步学习、百分比初态、共存线共同高度和总量约束。

## 验证

- 全站30项测试通过。本次新增三维相机旋转测试：遍历转向/俯仰，检查向量长度守恒、有限值、两个旋转方向及深度坐标。物理测试仍通过。
- 浏览器实操斜向拖动同时改变转向和俯仰；滚轮改变缩放；方向键与加号修改后刷新能恢复；恢复按钮回到默认视角。
- 高度差1倍与4倍对比，实际g读数均为固相−0.0474、液相−0.1294、气相0.1637；屏幕所选点之间的高度间隔增大。
- 320/390像素视口页面无横向溢出，主要控件及共享三维图可见；恢复默认视口后检查WebGL实际显示和浏览器日志。
- WebGL着色器成功编译并显示三张曲面；检查默认低俯角和另一侧高俯角，曲面前后遮挡随视角改变。
