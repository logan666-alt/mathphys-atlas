# 三相专题第二版核验

此文件记录最初第二版的历史验收。后续按用户反馈取消并排与液相参考差值视图，当前修订见 `verification-three-phase-orbit.md`。

日期：2026-10-27。入口：`/#/resource/three-phase`。

## 变更

学习顺序为比较三相高低、沿线看共存、改变相比例。每次只显示当前任务的图和控件；初始状态只保留主要情景，温压微调、额外情景、公式、摩尔量表及总量约束按需展开。

三张曲面默认并排，采用相同局部窗口、视角和纵轴尺度。差异视图绘制 g_i−g_liquid：三相在每个温压点减去同一参考，因此化学势差与相等位置不变。纵向采用适合当前窗口的放大尺度；不为不同相人为添加高度偏移。关闭差异模式可看实际g曲面。独立高度差图和每张曲面下方的实际g读数用于定量比较。第二步新增实际共同g随共存压强的曲线，避免从差值曲面误读共同高度。

初态改为直接百分比，修改一相后另两相按原比例分配剩余量；纯相端点无剩余权重时等分给另外两相。终态控件只在存在相比例自由度时出现；三相点分别调固相比例和余下液气内的气相比例。

## 已完成检查

- 原有物理模型不变，10项本专题测试通过；全站29项测试通过。新增百分比分配测试覆盖三相及纯相端点，检查指定比例、非负性、归一化与其余两相比例。
- 第一、二、三步切换，当前步骤及温压状态可通过URL恢复。由自由相区进入第二步时自动定位汽化线，界面显示新温压。
- 默认液相区实际g：固相−0.0474、液相−0.1294、气相0.1637；差异视图的实际读数保持一致。
- 并排、叠合、下包络、关闭差异放大、温压微调、曲面拖动和恢复视角完成实操。拖动将视角从−35°改为16°，恢复按钮回到−35°。
